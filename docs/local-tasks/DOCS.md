# Local tasks

The local folder task format: tasks as markdown files in one root folder, managed only through a
bundled script.

## Docs

- `format.md` — the file format, the field meanings, and every operation with its command. Use when
  creating, reading, updating or completing a task in a local task folder.

## Helper directories

- `scripts/` — `tasks.py`, the only thing that reads or writes the store. Run it; do not read it
  for information.
