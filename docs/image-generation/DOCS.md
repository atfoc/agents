# Image generation

Generating images from a text description through the OpenRouter API with a bundled script.

## Docs

- `generating-images.md` — generating an image from a text prompt: the API key, the output path,
  reference images, transparent backgrounds, and the script command. Use when the user asks for an
  image, picture, icon, illustration or asset to be generated.

## Helper directories

- `scripts/` — `openrouter-imagegen.py`, which calls the API and writes the image, and
  `requirements.txt` for its optional dependency. Run it; do not read it for information.
